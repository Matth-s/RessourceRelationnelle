# (RE)Sources Relationnelles

Bienvenue sur la documentation technique du projet **(RE)Sources Relationnelles**.

## Présentation

Plateforme numérique du Ministère des Solidarités et de la Santé dédiée à 
l'amélioration des relations interpersonnelles.

## Stack technique

| Couche | Technologies |
|--------|-------------|
| Backend | ASP.NET Core, Entity Framework, C# |
| Frontend Admin | React 19, TypeScript, Tailwind, shadcn/ui |
| Frontend Mobile | React 19, TypeScript, Tailwind, Capacitor |
| Base de données | Supabase (PostgreSQL + Storage) |
| Authentification | JWT + ASP.NET Identity |
| Tests | xUnit, Moq, SQLite in-memory, Coverlet |
